# Aircraft Geolocation Project 🛩

A Python-based aircraft tracking system using real-time data.

## Included Files:
- avion_localisateur.py (main script)
- sample_data.py (sample data)  
- requirements.txt (dependencies)

## Features
- Real-time aircraft position tracking
- Data analysis and visualization capabilities
- Integration with public aviation APIs
